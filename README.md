## ✨ Features

### 🎨 Enhanced Text Display
- 📝 **Markdown Rendering:** Rich text formatting with headings, lists, code blocks, and styling  
- 🎨 **Syntax Highlighting:** Beautiful syntax highlighting for multiple programming languages  
- 📊 **Table Support:** Fully supports GitHub Flavored Markdown tables  
- 💬 **Blockquotes & Emphasis:** Enhanced typography with bold, italics, and quotes  

### 🤖 AI Interaction
- 🤖 **AI Chat:** Get intelligent and well-formatted answers from **Google Gemini API**  
- 💡 **Prompt Improvement:** Suggests better prompts for enhanced responses  
- ✒️ **Typing Animation:** Smooth typing animation for both answers and suggestions  
- 📋 **Enhanced Copy:** Copy individual sections or entire responses effortlessly  
- 💬 **Chat History:** Locally saved conversations to revisit anytime  
- 🗑️ **Clear History:** Start fresh anytime  

### 🛡️ Reliability & Performance
- 🔄 **Robust Error Handling:** 60-second timeout and user-friendly error messages  
- ⏳ **Enhanced Loading:** Beautiful animations and placeholders  
- 📱 **Mobile-First Design:** 90% responsive and auto-scroll supported  
- 📁 **Collapsible Sidebar:** Manage and navigate your chats easily
